# figures/data

Intermediate results read by the figure scripts (`*.npz`, `*.json`). They are produced by the `figdata_*.py`,
`compare_fair.py`, `tail_events.py`, `extremes_stations.py` and `make_tables_nature.py` scripts from the evaluation outputs
(`runs/<run>/eval_*/part_*.npz`), and are not versioned because of their size (2.3 GB).
